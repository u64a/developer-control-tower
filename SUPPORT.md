# Support

Use [GitHub Issues](https://github.com/u64a/developer-control-tower/issues) for
reproducible bugs and focused feature requests.

Before filing a bug:

1. Update to the latest release.
2. Confirm whether the workspace is local, SSH, hosted-only, or hybrid.
3. Reproduce with the smallest safe project configuration.
4. Attach relevant log excerpts only after removing personal paths,
   repository names, URLs, and confidential data.

Logs are stored under
`%LOCALAPPDATA%\DeveloperControlTower\logs`. Do not post credentials, private
repository content, or customer information.

Security reports belong in private vulnerability reporting, not Issues.
