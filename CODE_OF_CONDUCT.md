# Code of conduct

We want Developer Control Tower to be a professional and useful project.

Participants must:

- communicate respectfully and assume good intent;
- focus criticism on ideas and code, not people;
- avoid harassment, discrimination, threats, and disclosure of private data;
- respect security embargoes and confidential vulnerability reports;
- accept maintainer decisions about product scope and repository safety.

Maintainers may edit or remove content, close interactions, or restrict
participation when behavior undermines a safe and constructive environment.
Report conduct concerns privately to the maintainers through the repository's
security advisory channel.
